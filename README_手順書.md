# メルカリ割安商品検出ツール — セットアップ手順書

プログラミング未経験でも使えるよう、順を追って説明します。

---

## ツールの概要

1. ブラウザが自動で起動し、メルカリで「パタゴニア」「アークテリクス」を定期検索
2. 新着商品を発見するたびに、**売り切れ実績から相場価格を自動計算**
3. 出品価格が相場の **60% 以下**なら、**音 + ポップアップで即通知**
4. ポップアップから商品ページに直接ジャンプ可能

---

## セットアップ手順（初回のみ）

### ステップ 1 — Python をインストールする

1. ブラウザで `https://www.python.org/downloads/` を開く
2. 「Download Python 3.12.x」という緑のボタンをクリック
3. ダウンロードした `.exe` ファイルを実行
4. **★ 必ず「Add Python to PATH」にチェックを入れる ★**
5. 「Install Now」をクリックしてインストール完了

### ステップ 2 — ツールをセットアップする

1. このフォルダを開く
2. **`setup.bat`** をダブルクリック
3. 黒い画面が開いて自動でインストールが始まる
4. 「セットアップが完了しました」と表示されたら完了

---

## 使い方（毎回の起動）

1. **`start.bat`** をダブルクリック
2. ブラウザが自動で起動し、メルカリが開く
3. アプリのウィンドウが表示されたら「▶ 監視開始」ボタンを押す
4. あとは自動で動きます。割安商品を発見すると音が鳴って通知が来ます

---

## 設定の変更方法

`config.py` をメモ帳で開いて編集できます。

| 設定項目 | 初期値 | 説明 |
|---------|--------|------|
| `KEYWORDS` | `["パタゴニア", "アークテリクス"]` | 監視するブランド名 |
| `PRICE_RATIO_THRESHOLD` | `0.60` | 相場の何%以下で通知するか（0.60 = 60%） |
| `CHECK_INTERVAL_SECONDS` | `90` | 何秒ごとにメルカリを再チェックするか |
| `MIN_PRICE` | `1000` | 1,000円未満の商品は無視 |
| `MAX_PRICE` | `300000` | 30万円超の商品は無視 |

## 注意事項

### 精度の限界について
- 画像からではなく、**商品タイトルのテキスト**で相場を検索しています
- 商品名が曖昧（「パタゴニア フリース 青 M」など）だとサンプル数が少なくなることがあります
- サンプルが 3 件未満の場合は「データ不足」としてスキップします

### メルカリのサイト変更について
- メルカリのウェブサイトは構造が変わることがあります
- 「商品リストのセレクタが見つかりません」というログが出た場合は、
  開発者にお知らせください

### 過度な利用について
- 短すぎる間隔（30秒未満）でのチェックはメルカリのサーバーに負荷をかけます
- デフォルトの 90 秒間隔での利用を推奨します

### Google 検索の CAPTCHA について
- メルカリのデータが不足した場合のみ Google 検索が走ります
- Google に「ロボット確認」が表示された場合、ツールは 30 秒待機して再試行します

---

## よくあるエラーと対処

| エラーメッセージ | 原因 | 対処 |
|---------------|------|------|
| `Python が見つかりません` | Python 未インストール or PATH 未設定 | ステップ 1 をやり直す（Add to PATH にチェック必須） |
| `Playwright のインストールに失敗` | ネットワークエラー | `setup.bat` を再実行 |
| `ブラウザが起動しない` | Chromium 未ダウンロード | `setup.bat` を再実行 |
| `新着: 0 件` が続く | セレクタ変更 or ネットワーク問題 | 開発者に連絡、またはメルカリが混雑している |
